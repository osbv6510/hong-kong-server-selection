## 香港服务器租用平台其实分三类，先对号入座

香港的服务器供应方大致分三类，选错类别比选错套餐更浪费钱。

第一类是云厂商，阿里云国际、腾讯云香港、UCloud 都在里面。优势是控制台完善、能弹性扩容、有正规 SLA 和开票流程；代价是同配置单价高，入门套餐的带宽通常很小，跑大流量业务账单容易失控。

## 几个买之前最常问的问题

**香港 VPS 需要备案吗？** 不需要。香港机房不受大陆备案制度约束，域名解析过去即可上线，这也是很多人选香港而不是大陆机房的主要原因。

**1Gbps 端口是独享还是共享？** 官方只标 “1Gbps VirtIO Port” 这类端口规格，没有承诺独享带宽。第三方测试记录里出现过 “2 Gbps IN | 2 Gbps OUT (Shared)” 的描述。需要带宽保证的场景，别按独享去规划。

**流量用超了会怎样？** VPS 可能被限速，具体阈值官方没公布；Forge 独立服务器按 $0.06/GB 计费。流量配额在每个计费周期开始时重置。

**IP 被墙了怎么办？** 官方流程是先判断是否全球不可达，再用 ping 和 traceroute 诊断，然后开工单核实 IP 状态，确认被封会协助更换。官方同时提示，IP 被封通常和服务器上跑的服务有关。

**能先试用吗？** 没有免费试用，但有 24 小时无风险退款，等于花一个月的钱换一天的实测窗口。真要用这个窗口，建议开通当天就把路由、延迟、磁盘 IO 都跑一遍。
